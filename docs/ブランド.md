## 2. 由来・コンセプト

**煙道 =「煙の通り道」。** 茶道・華道・**香道**に連なる “道” として、本場の作り方を取り込みつつ
**日本流に洗練されたシーシャの作法**を体系化する——という物語を名前そのものに込める。

- 「道」＝ 型・定石・免許皆伝 → プロダクトの **鉄板レシピ（迷わない基準）** と **達人（プロ認証）** に対応。
- 中核概念「**日本代表シーシャ図鑑**」＝ みんなで育てる日本の“美味しい”基準（詳細は `事業計画.md`）。
- 英字 **ENDOH** は短く・母音終わりで海外でも発音容易。姓「遠藤」と同綴りだが、ブランド文脈で上書きする。

> 補足：「煙道」は一般語で “煙突・排煙路（flue）” の意味も持つ。これは弱点ではなく **原義（煙の通り道）** として
> reclaim し、由来の詩として活かす方針。

## 3. タグライン

- 情緒：**「煙を、味わう。」**（香道オマージュ）
- 機能：**日本代表シーシャ図鑑**
- 海外向け：*The Japanese way of shisha.*

## 4. ロゴ／マーク（意匠は「和」）

意匠 = **washi（和紙・生成り）× 墨（sumi）× 苔緑（moss green）× 朱の落款（vermilion seal）**、書体は**明朝体（Shippori Mincho）**。

- **マーク**：角丸スクエアの**朱の落款**（`--color-seal` #b23b2e）に生成り（#fbf8f0）で白抜きの **煙**。ヘッダーは `.seal-stamp`（わずかに傾けた印影）。
- **ワードマーク**：`煙道`（明朝＝`.brand-mark`）＋ 小さめ大文字 `ENDOH`（苔緑 `--color-ember-hot`、レター spacing 広め）をベースライン揃えで併記。
- ヘッダー：`components/site-header.tsx` / フッター：`components/site-footer.tsx`。
- ラスター画像（favicon・OG）は `next/og` で生成。CJK 描画のため **サブセットフォント `app/brand-jp.ttf`** を同梱し読み込む
  （`app/icon.tsx` / `app/opengraph-image.tsx`）。※同梱フォントは Gothic 系のため、本文の明朝とは書体が異なる点に留意（豆腐回避と自己完結を優先）。フォント差し替え時は必要グリフを含め再サブセットすること。

## 6. 声のトーン（Voice）

- 職人的だが敷居は低い。断定しすぎず「まずこれ」と背中を押す。
- 「迷わない」「日本代表」「鉄板」を軸語に。シーシャは「**吸う**」（「飲む」は使わない）。過度な煽り・誇大表現は避ける（`docs/リスク管理.md` 準拠）。
