# 煙道 ENDO — 基本方針（プロダクトの背骨）

> このドキュメントは煙道の**基本コンセプト＝今後の実装・意思決定の最上位指針**である。
> `事業計画.md`（詳細メモ）・`ブランド.md`（表記）より上位。迷ったらここに立ち返る。
> 最終更新: 2026-08-13（レシピ共有寄りの初期構想から「共創プラットフォーム」へ一段引き上げ）

## 一言で

**「日本のシーシャの"王道"を、みんなでつくる。」**

煙道は、ミックス・作り方・実際に吸った評価・店舗をつなぎ、日本人の舌に合うシーシャの基準を
みんなで育てる**共創プラットフォーム**。単なる「レシピサイト／図鑑」ではない。
「探す場所 → 作る場所 → 吸う場所 → 評価する場所 → 学ぶ場所 → 記録する場所」まで広がる。

> ⚠️ 用語：シーシャは「**吸う**」（「飲む」は使わない）。

## 1. 煙道とは何か
「迷ったら、まずこれ」という**王道**をつくる共創型プラットフォーム。フレーバーの組み合わせだけでなく、
**配合・盛り方・ボウル・HMD・炭・蒸らし・熱管理まで含めた「一台の作り方」**を共有する。
その作り方を**実際に吸った人が評価**し、評価と検証を積み重ね、**多くの支持を集めた作り方がそのミックスの「王道」**になる。
プロが一方的に正解を教えるのでも、人気投票だけで決めるのでもない。**作る→吸う→評価する→改良する**の反復で、
日本人の舌に合うシーシャの基準をみんなで育てる。

## 2. 解決する問題
シーシャには「正解」がほとんど残っていない。ネットには「この2つが美味しい」までしかなく、
**何対何・何g・どう盛る・どのボウル・炭いくつ・何分蒸らす・熱をどう動かす**まで分からない。
だから同じミックスでも同じ味にならない。一方、初心者に全部見せると難しすぎる。**煙道はこの両方を解決する。**

## 3. 「初心者」と「作り手」を分断しない（最重要思想）
初めて作る人・趣味の人・毎日店で作るプロを**別サービスにしない**。
- 初心者 → **迷ったら、まず王道**（必要最低限の作り方）
- もっと知りたい人 → **なぜこの作り方なのか**
- 作り込む人 → 熱管理カーブ・g・ボウル・HMD・炭移動などの詳細データ

＝**「初心者用／プロ用」ではなく、"知りたい深さに応じて同じ一台を深く掘っていける"設計**。
（表示モードは"属性"でなく"見せる情報量（シンプル/詳細）"。ブランド「道」と相性が良い。）

## 4. 「王道」とは（サービス独自概念・明文化）
**王道 = 多くの人が実際に吸い、支持し、再現されてきた、そのミックスの基準となる作り方。**
単なる「人気1位」ではない。複数の作り方を**実吸評価・評価人数・再現性・継続的な支持**から判断する。
そして**王道は永久固定ではない**——もっと美味しい作り方が生まれれば更新される。
＝**王道は"決める"ものではなく"育てる"もの。**

## 5. ユーザー体験の中心：探す → 作る → 吸う → 残す → 深める
- **探す**：気分・味・フレーバー・手持ち・店舗から今日の一台を見つける
- **作る**：まず王道をそのまま再現、慣れれば自分の作り方に挑戦
- **吸う**：自宅でも店舗でも体験し、可能なら**店舗での実吸を認証**
- **残す**：評価・感想・吸った履歴を**「煙道帳」**に蓄積
- **深める**：他の作り手の方法を比較・自分も投稿し、より良い王道づくりに参加

**この循環そのものがプロダクト。**

## 6. 「図鑑」の意味も変わる
単なる一覧ではなく、1ミックスに **味覚プロファイル／王道レシピ／別の作り方／実吸評価／再現性／作り手／
使用フレーバー／必要な器具／似たミックス／この王道を吸える店舗** が紐づく。
＝「図鑑」というより**日本のシーシャの知識体系（Wikipedia的）**。

## 7. 「達人」の意味
プロ機能は単なるプロフィールにしない。**美味しいシーシャを作れる人そのものに価値**を持たせる。
作り手には **投稿した作り方／実吸評価／再現された回数／王道獲得数／得意ジャンル** が蓄積され、
実績に応じて**段位・達人認証**を与える。＝**「フォロワーが多い人」でなく"実際に美味しい一台を生む人"が評価されるSNS**。

## 8. 店舗の位置づけ（広告主ではない）
店舗は**オンラインデータと現実のシーシャ体験をつなぐ場所**。
`王道を見つける →「この王道を吸える店」→ 店舗で吸う → 評価 → 王道に反映`＝
**オンライン→店舗→実吸→データ→オンライン**のループ。
在庫データから「この店ならどの王道を作れるか」を自動判定し、将来は
**「このフレーバーを仕入れると人気王道が○件作れる」**という仕入れ支援（B2B）まで。

## 9. マイ煙道（重要な柱）
使うほど**自分だけのシーシャの記録**が育つ：持っているフレーバー／吸ったミックス／評価／お気に入り／
吸いたい／訪れた店舗／好みの味／好きな作り手。やがて**好み（甘さ・爽快感・濃厚さ…）**まで可視化。
＝**検索して終わりでなく、再訪する理由**になる。

## 10. 煙道が持つ「3つのデータ」（最終的な価値）
1. **味のデータ**：どの組み合わせを誰がどう評価したか
2. **技術のデータ**：どう作れば美味しくなるか
3. **店舗のデータ**：どこに何があり、何を実際に吸えるか

この3つが繋がると「**何を吸うか／どう作るか／どこで吸うか**」を全部煙道で解決できる。

## 11. 事業ポジション
「シーシャレシピサイト」と定義**しない**。**「日本のシーシャの知識と体験を蓄積するプラットフォーム」**と定義する。
その**入口＝ユーザーから見た分かりやすい顔**として「**王道シーシャ図鑑**」がある（この順番）。

## 12. ブランド思想
**煙道 = 煙の通り道 / シーシャという「道」**。茶道・香道のように
`型を知る → 繰り返す → 違いが分かる → 自分の型を見つける → 次の人へ伝える`。
だから初心者に「まず王道」を示すが、王道だけを押し付けない。最終的には**「自分の一台」**に辿り着く。

## 実装への含意（このコンセプトから導かれる設計原則）
- **段階開示を徹底**：どの画面も「結論（王道／まずこの作り方）→ なぜ → 詳細データ」の順に深掘れる。モード非依存。
- **評価は"実際に吸った"を最重視**：いいねより「作った」「実地評価」。王道選出は実吸を核に。
- **記録を資産化**：煙道帳・マイ煙道・作り手実績を蓄積し、再訪と信頼の源にする。
- **店舗はループの一部**：広告でなく「実吸→データ→王道」を回す装置として設計。
- **機能を足しすぎない**：`機能ロードマップ.md` の ①ローンチ必須 → ②ローンチ後 → ③将来構想 の段階に従い、
  一度に全部入れてゴチャつかせない。
