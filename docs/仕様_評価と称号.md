# 煙道 ENDO — 確定仕様：味覚プロファイル / 王道 / 達人（段位・称号）

> `基本方針.md` に基づく**確定仕様**。味覚評価・王道の見せ方・作り手の段位/称号の設計。
> 貫く思想：**初心者には数字を意識させない。玄人には数字の奥まで見せる。裏では最初から細かくデータを取る。**
> （＝段階開示。「初心者版/プロ版に分断しない、深く潜れる煙道」と直結）
> V1はシンプルに始めつつ、**データ蓄積後でも破綻しない**データ設計にする。
> 最終更新: 2026-08-13

---

## 0. 大前提
**王道を人気ランキング化しない。** 「いいね数1位」ではなく、実吸評価・評価人数・再現性・継続的支持で判断する。
"王道"は**頂点の称号**として守り、何でも「王道」と呼ばない。

---

## 1. 味覚プロファイル（V1確定）

### 軸：5軸（「香り」は入れない、「酸味」を入れる）
**甘さ ｜ 爽快感 ｜ 酸味 ｜ 濃厚さ ｜ 重さ**
- 「香り」除外：強弱だけでは良し悪し/華やか/香ばしいが判別できず検索に使いにくい。
- 「酸味」採用：レモン・ライム・グレフル・ベリー系の探索に有効。

各軸 **1〜5**。アンカー定義を固定：

| 軸 | 1 | 3 | 5 |
|---|---|---|---|
| 甘さ | 甘さ控えめ | 甘さを感じる | デザート級 |
| 爽快感 | 清涼感なし | 程よく爽快 | 強冷感 |
| 酸味 | ほぼなし | 適度な酸味 | 強い酸味 |
| 濃厚さ | 軽く淡い | 味がしっかり | 非常に濃厚 |
| 重さ | 軽く吸える | 標準 | 重厚・吸いごたえ |

### 誰が付けるか：**投稿者ではなく"実際に吸った人"の評価の平均**
毎回5項目入力は面倒なので、実吸評価（と作った人）の入力から**平均値**を作る。投稿者の自己申告に依存しない。

### 味系統は"別データ"として持つ（数値と分離）
数値5軸（＝どんな強さの味か）とは別に、**味系統タグ**（何系の味か）を持つ：
`フルーツ / シトラス / ベリー / トロピカル / フローラル / ハーブ / スパイス / デザート / ドリンク / ミント・清涼 / その他`
- 例：Mango×Ice Aqua → 甘さ★4/爽快★4/酸味★2/濃厚★3/重さ★2、`#トロピカル #フルーツ #清涼`
- **数値＝強さ／タグ＝系統** を分離＝将来のレコメンドに使いやすい。
- （注：既存の `taste_tags` が味系統タグに相当。5軸の数値は新規。）

### 表示（段階開示）
- 初心者：「**甘め・爽快・軽め**」程度の言葉で。数字（甘さ4.2、酸味1.8…）は見せない。
- 「詳しく見る」を押した人：5軸の数値・実吸信頼度まで全部見せる。

## 2. 王道（V1確定）

### V1は「総合王道」1つだけ
初心者王道・濃厚派王道・Kaloud王道… を**最初から作らない**。理由：データが分散し「結局どれが王道？」となり、
中核価値「**迷ったら、まずこれ**」と矛盾するため。

### ただし内部データは最初から持つ（将来の派生に備える）
表示は `🏆 王道` を1つ＋「**別の作り方を見る（N）**」。
各作り方に**内部属性**を最初から付与：`初心者向け / 濃厚 / 軽め / 爽快 / Kaloud / Provost / アルミ / ターキッシュ / ファンネル` など。
→ データが貯まれば後から「初心者に支持 4.91」「濃厚派評価 4.86」等を展開できる。

### 複数王道の解禁順（データ蓄積後）
① 総合王道 → ② **はじめの王道**（"迷わない"思想と最も相性がよい／最初の派生） → ③ 味の好み別 → ④ 器具別（マニアックゆえ後）

### 名称ルール（"王道"は守る）
何でも「王道」と呼ばない。頂点＝`🏆 王道` のみ。派生は別称にする：
`🔰 はじめの王道`（例外的に"王道"を許容）／`🔥 濃厚派の定石`／`🫧 爽快派の定石` …「定石」等で頂点と区別。

## 3. 達人（段位・称号）（V1確定）

### 原則
- **王道獲得数だけで決めない**（古参・投稿量が有利になるのを避ける）。評価するのは
  「**実際に、美味しく、再現できる作り方を残した人**」。
- **プロ（職業・所属）と 達人（煙道内の実績）を分離**。店舗勤務でなくても高段位になれる。
- **段位（総合実績）と 称号（得意分野）を分離**。

### 煙道スコア（内部値・重み）
| 要素 | 重み | 中身 |
|---|---|---|
| ① 実吸評価 | **40%** | 単純平均でなく **評価点 × 信頼できる実吸数**。★5×3人より ★4×300人を高評価。店舗QR等 **Verified実吸はさらに重く**。 |
| ② 再現実績 | **30%** | 他ユーザーがその作り方で**実際に作った回数**。「再現して美味しかった」まで取れれば最良。作り方共有サービスゆえ再現性を重視。 |
| ③ 王道実績 | **20%** | 王道になった作り方を持つ。ただし数でなく**その王道がどれだけ吸われ・再現されたか**を重視。 |
| ④ コミュニティ貢献 | **10%** | 投稿数ではない。他人のレシピの実吸評価・ノウハウ投稿・改善提案・正確なフレーバー情報登録など、**知識を育てた活動**。 |

### 昇段は「最低条件 ＋ スコア」（点数だけで上げない）
一つのバズりレシピだけで最高段位になるのを防ぐ。例：
| 段位 | 最低条件 | ＋ |
|---|---|---|
| 初段 | 実吸評価 30件以上・再現 10件以上 | 煙道スコア ◯以上 |
| 二段 | 実吸評価 100件以上・再現 30件以上・高評価レシピ3件以上 | 煙道スコア ◯以上 |
| 三段 | 実吸評価 300件以上・再現 100件以上・王道獲得1件以上 | 煙道スコア ◯以上 |
| …四段・五段… | （同様に逓増） | |

### 段位 と 称号
- **段位**＝総合実績：一段・二段・三段・四段・五段 …
- **称号**＝得意分野：「果実の達人」「清涼の達人」「ダブルアップルの達人」「熱管理の達人」…
- プロフィール例：`煙道 四段・果実の達人` ／ `山田太郎｜認証プロ ○○SHISHA(東京)｜煙道 三段｜王道2・実吸486・再現132`

## 4. V1まとめ表
| 項目 | V1 |
|---|---|
| 味覚 | 甘さ・爽快感・酸味・濃厚さ・重さ（各1〜5、実吸評価の平均） |
| 味分類 | 別途タグ（味系統） |
| 王道 | 1ミックスにつき総合王道1つ。他は「別の作り方」として保持（内部属性付き） |
| 複数王道 | データ蓄積後。最初の派生＝「はじめの王道」 |
| 達人評価 | 実吸40 / 再現30 / 王道20 / 貢献10（内部・煙道スコア） |
| 昇段 | 最低条件 ＋ 煙道スコア |
| プロ | 職業・店舗所属の認証（達人とは別） |
| 段位 | 煙道内の実績（一〜五段…） |
| 称号 | 得意分野（果実の達人 等） |

## 5. 実装メモ（ロードマップとの対応）
- 味覚5軸＝**②ローンチ後**（実吸評価に軸入力を足す／平均集計／段階開示で表示）。
- 作り方の**内部属性タグ**は、複数王道解禁前でも**投稿/編集時に裏で持ち始めてよい**（表示はしない）。
- 達人スコア・段位・称号＝**②ローンチ後**（プロ認証は既存）。
- **数値は裏で最初から取り、表では段階開示**（初心者は言葉、玄人は数値）。＝①ミックス詳細の段階開示が土台。
