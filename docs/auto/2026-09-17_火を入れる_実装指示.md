「火を入れる」は **2026-08-19 の判断で唯一の例外** として残す、と明記されている。
例外でいられる条件は次の4つ。**1つでも破ったら、それはゲーミフィケーションなので作らない。**

- 点・バッジ・順位・連続記録を**与えない**
- 状態を**保存しない**（DB にも localStorage にも書かない）

## 3. 作るもの

`components/fire-button.tsx`（`'use client'`）を新規に1つ。上の2か所から呼ぶだけにする。

```
<div className="fire">
  <button type="button" className="fire-btn" …>
    <span className="fire-coal" aria-hidden><span className="fire-glow" /></span>
    長押しで火を入れる
  </button>
  <p className="fire-status" aria-live="polite">{status}</p>
</div>
```

動き：

- `pointerdown`（＋キーボードの Space / Enter の押しっぱなし）で溜まり始める。
- `requestAnimationFrame` で経過時間を見て `--fire` を 0→1 に上げる。**約1.2秒で満ちる。**
  値は `el.style.setProperty('--fire', v)` で**変わったときだけ**書く（毎フレーム書かない）。
- 満ちたら、その要素の一番近い `.smoke-stage`（無ければ自分の親）に `is-lit` を付け、
  `fire-status` を「火が入った」に変える。**そこで終わり。**
- `pointerup` / `pointercancel` / `pointerleave` / `blur` で、満ちる前なら 0 に戻す。
  戻すのも rAF で（急に0にしない）。
- 一度点いたら押しても何も起きない（CSS 側で `cursor: default` になっている）。

## 4. 外してはいけない決まり

1. **見せるために JS を必要としない。** 既定は「見えている」。
   JS が動かない環境でもボタンは**そのまま描かれ**、押しても何も起きないだけにする。
   `opacity: 0` で始めて JS で出す、のような作りにしない（2026-08-20 に2件やって本文が消えた）。
2. **動きが苦手な設定**（`prefers-reduced-motion: reduce`）のときは溜めない。
   押した瞬間に `--fire: 1` と `is-lit` にする。門の条件式は
   `components/scrub-hero.tsx` の `GATES` と**字句まで一致**させること。
3. **色は増やさない。** 使うのは既にある `--color-seal` / `--color-ember-deep` 系だけ。
   橙は「実際に火がある所」なので、ここは橙でよい唯一の場所。
4. **絵文字を使わない。** 炭は `.fire-coal` の丸（CSS）で表す。
5. **塗りの上に白文字を置かない。** ボタンの地は透明のまま。
6. 保存しない・数えない・次を要求しない（第1節の4条件）。
