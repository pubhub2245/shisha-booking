# 更新を検索エンジンに知らせる仕組み（IndexNow）— 煙道 ENDO

2026-09-18。公開したばかりで検索に拾われていないため、待つのではなく
こちらから「このURLを見に来て」と知らせる。Bing・DuckDuckGo などが対応（Google は非対応）。
**無料・アカウント不要・課金なし。**

## 入れたもの

| もの | 中身 |
|---|---|
| `public/<鍵>.txt` | 鍵の唯一の正。中身とファイル名が同じ文字列。鍵は秘密ではなく、「このサイトの持ち主が送っている」ことを示すだけのもの |
| `scripts/indexnow.mjs` | 送る処理。公開中の `/sitemap.xml` を読み、その `<loc>` をそのまま送る |
| `package.json` の `postbuild` | 本番ビルド（`VERCEL_ENV=production`）のときだけ自動で走る。プレビューと手元では何も送らない |

## 決めたこと（ほかの4サイトと違う点）

煙道のページ一覧は中身（フレーバー・作り方）から毎回作られる作り（`force-dynamic`）なので、
ビルドの成果物に出来上がった `sitemap.xml` が無い。そのため **公開中のサイトの
`/sitemap.xml` をそのまま読む**。読めなければ何も送らずに終わる。

## 守っていること

- **この処理でビルドを失敗させない。** 送信に失敗しても記録を出して終了コード0で終わる
- 鍵をコードに書かない（`public/<鍵>.txt` が唯一の正）
- 送り先は IndexNow の公式の受け口のみ。個人を見分ける情報は何も送らない

## 実測（2026-09-18）

- 公開中のページ一覧：**120件**、すべて `https://shisha-booking.vercel.app`
- `robots.txt` … 検索から外しているのは `/mypage` `/post` `/api` のみ
- `npm run indexnow -- --dry-run` … 送る予定120件・鍵の置き場を表示して送信なしで終了

## 使い方

```
npm run indexnow -- --dry-run   # 送らずに件数だけ見る
npm run indexnow                # 手で送る
```
