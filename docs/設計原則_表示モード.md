# 煙道 ENDO — 設計原則：表示モードを持たない

> `CLAUDE.md` の設計原則「ユーザーを分ける永続的なモードを作らない」の背景・経緯。
> ルール本体は CLAUDE.md にあり、ここはその理由を残すための記録。

## 表示モードを持たない（過去の失敗から確定）

**ユーザーを分ける永続的な「モード」を作らない。** 初心者/プロで分けない方針だったにもかかわらず、
一度は `profiles.ui_mode`（シンプル/詳細）として実装が残ってしまった。**名前を変えても本質は同じ**で、
「あなたはどちら？」と最初に選ばせ、その選択で見えるものが変わる時点で、それはユーザーの属性分けである。

確定した設計：
- **グローバルな表示モードは存在しない**（`lib/mode.ts`・モード切替UI・`setUiMode` は撤去済み）
- 情報量の出し分けは**画面ごと・セクションごとの段階開示**で行う（`<details>` で「詳しく見る」）。
  全員が同じ「結論」を見て、知りたい人だけがその場で深く潜る
- 選択させるなら**その都度の行動単位**にする。例：投稿時の「かんたんに投稿／詳しく投稿」は
  毎回選び直せる行動の選択であって、ユーザーに貼られる属性ラベルではない（これは可）
- 迷ったら「この選択はユーザーに貼られ続けるか？」と問う。貼られ続けるなら作らない
