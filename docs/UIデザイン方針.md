# MixHub UIデザイン方針

> 「Instagram / X などに寄せるか？」という問いへの結論と指針。
> **一言でいうと：操作パターンは寄せる。見た目のブランドと“図鑑の中身”は独自を貫く。**

---

## 基本原則（3つ）

1. **操作パターンは有名アプリに寄せる** — ユーザーが説明なしで使える（学習コストゼロ）。
2. **見た目のブランドは独自を貫く** — 配色・ロゴ・世界観。差別化と権利の両面。
3. **図鑑／作り方の可視化を主役にする** — ここが MixHub 最大の価値であり moat（他アプリに無い）。

判断に迷ったら合言葉：**「“操作”なら寄せる／“見た目と中身”は独自」**。
そして必ず自問する：**「これ Instagram でよくない？」と言われない構造になっているか？**（＝図鑑が主役か）

---

## 寄せる（借りてよい）— 操作・インタラクション

| 要素 | 参考 | MixHub での適用 | 現状 |
|---|---|---|---|
| 下タブナビ | IG / X | 既存のモバイルナビ | ✅ |
| タップでいいね（即時反応・ハート演出） | IG | mix カード・詳細 | 一部 |
| 写真グリッド（プロフィール・一覧） | IG | 盛り方写真を活かした画像先行表示 | ⏳（写真機能追加済＝好機） |
| プル更新／無限スクロール | IG / X | フィード | 検討 |
| フォロー・タイムライン | X / IG | 既存 | ✅ |
| 引用（＝フォーク投稿） | X | 既存 | ✅ |
| タグ／ハッシュ | X | 味わい・系統タグ | ✅ |
| 共有・リンク | 共通 | シェアボタン | ✅ |

→ **次の一手候補：写真中心化（プロフィール/一覧を画像グリッド、写真先行カード）**。追加した盛り方写真と最も相性が良い。

---

## 寄せない（独自を貫く）— 見た目と図鑑

- **配色（smoke / ember の温かみ）・ロゴ・タイポグラフィ**：MixHub 独自のまま。
- **プロ認証などのバッジ表現**：他アプリの認証マークを模倣しない（独自の見せ方）。
- **図鑑コア＝ MixHub 固有の資産**。フィードに埋もれさせない：
  - 熱管理カーブ（蒸らし区間・到達火力・炭の本数）
  - セットアップのイラスト（HMS／ボウル／盛り方）
  - HMD × ボウルの相性、温度で変わる味
  - 作り方ガイド

---

## レッドライン（やらない）

- 特定アプリの**配色・ロゴ・画面をそっくり複製**する（権利／ストア審査／“劣化コピー”リスク）。
- 認証バッジ等の**そっくり模倣**。
- 図鑑の深さを**一般的なフィードに薄める**（差別化の喪失）。

---

## 具体化の優先順（提案）

1. **写真中心化（IG 的な見せ方）** — プロフィール／一覧を画像グリッド、写真先行のカード。
2. **いいね等の即時反応・マイクロインタラクション（IG / X 的）** — 体験の手触りを磨く。
3. **図鑑の可視化をさらに強化（独自）** — カーブ・相性・実例ギャラリーの拡充。

いずれも「操作は馴染みやすく、中身と見た目は MixHub らしく」を満たす範囲で進める。
