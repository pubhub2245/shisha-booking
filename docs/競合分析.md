# 競合・市場分析（シーシャ ミックス図鑑）

> 作成: 2026-07（Web調査ベース）。数値の一部は公称値・推定を含む。事業判断の参考資料。
> ※ SimilarW/data.ai 等の生アクセス数は未取得（403）。MAU/月間訪問は公称値とDL数からの推定。

## 0. 結論（先に）

- **海外は激戦（SmokeDexの一人勝ち）／日本は空白。**
- 日本には「投稿・いいね・検索できるコミュニティDB／図鑑アプリ」が**存在しない**（記事型メディアのみ）→ 国内で先行者を取れる。
- 差別化の核は **①熱管理の構造化（競合に無い）②日本語コミュニティ ③フレーバー購入アフィリエイト ④プロ認証**。
- 戦略：**まず日本で勝つ（ビーチヘッド）**。世界展開は日本で手応えが出てから。
- 競合の看板機能 **「デジタル棚（My Shelf）」** は取り入れる価値大。

## 1. 海外競合

### SmokeDex（本命・世界最大） — smokedex.info
- 2016年〜。「世界最大のシーシャDB／コミュニティ」を公称。ニッチ内で世界ランク上位（2023時点で該当比較ページ内 #78）。
- **規模（公称）**: 25万ユーザー / アクティブ1万人超 / 1日数千人訪問 / 商品2万点超。推定月間訪問は十数万〜数十万オーダー。
- **機能**: Mixology（コミュニティレシピ数千件・割合入力・保存）、**デジタル棚（持っているフレーバーと照合）**、AIミックス推薦、店舗マップ/ディレクトリ、フレーバーレビュー。英/独中心。
- **運営/収益**: シーシャ専門マーケ代理店 **Smoke Corporation（業歴15年超）** のコミュニティ部門。
  - **自社EC「HookahFloW」**（独で最高評価の通販・25万顧客）へ送客
  - **ブランド/メーカー向け広告・ターゲティング販促**
  - 店舗・ブランドの**ディレクトリ掲載**
  - → 「コミュニティ／図鑑 → 自社EC＋ブランド広告」で**マネタイズ成立**。※アフィリエイトではなく**垂直統合（自社在庫EC）＋広告**型。

## 2. 日本市場

- **専用アプリ／コミュニティDB／図鑑は存在しない。**
- 存在するのは**記事型メディア／ブログ**のみ（＝おすすめ組み合わせ記事。投稿・いいね・検索のUGCではない）:
  - CLOUD（cloud-jp.net／「日本最大級シーシャ情報サイト」）
  - JAPAN SHISHA TIMES（専門店監修メディア）
  - BEYOND VAPE JAPAN / Marble Shisha / ASLAJ / Dr.Shisha / note個人ブログ 等
- → **国内は空白。先行者利益を狙える。**

---

## 3. MixHub の差別化ポイント

1. **熱管理の構造化**（火力1-100カーブ・炭セットアップ・炭イベント・作り方比較）
   - 海外勢もブログも熱管理は「文章のコツ」止まり。**データ化・グラフ化している所は皆無** ＝ 唯一無二の玄人価値。
2. **日本語ファースト**のUX・コミュニティ（SmokeDexは英/独）。
3. **フレーバー購入アフィリエイト（国内EC送客・成果報酬）**。
4. **プロ認証（店舗スタッフ）** による信頼性・指名。
5. **Combo × Method**（同一組み合わせの作り方を熱カーブで比較）＋**作り込み度で丁寧な投稿が上位**。

---

## 4. 競合から取り入れる価値のある機能

- **デジタル棚（My Shelf）**: 「持っているフレーバー」を登録 → **今作れるミックスだけ絞り込み**。SmokeDexの看板・高粘着。→ MixHubにも実装価値大。
- **AIミックス推薦**（SmokeDex/HookahX）: 将来の差別化候補。
- **ブランド公式ミックス**（Shisha Soul）: メーカー巻き込み。
- **フレーバーのレビュー/評価**（SmokeDex）。

---

## 5. マネタイズ設計（MixHubの方針）

- **提携EC × 成果報酬（CPA/アフィリエイト）**: リンクから送客 → 購入/クリック数で精算。現状のリンク構造と合致。
  - 将来: `/go?u=…`（クリックを記録して転送する中継リンク）で提携先ごとの送客実績を可視化 → 直接提携の精算に使える。
- 収益の“本命”は SmokeDex 型の **ブランド/店舗の有料販促** レイヤー（アフィリエイトより高利益）。将来の積み増し候補。
- **有料ノート**（作り方ノウハウ販売）はフェーズ3（決済＝課金実装が絡むため要相談）。

---

## 6. 収益規模の期待値（現実的に）

- シーシャは**ニッチ市場**。日本単独ならなおさら小さい。
- 現実解は「**手堅く黒字化できるスモール〜ミドルなビジネス**」。
- 爆発を狙うなら（a）世界展開、（b）ブランド販促・自社/送客コマース、（c）有料ノート、の積み増しが必要。
